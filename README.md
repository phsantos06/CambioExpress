# Cambio Express

Site de casa de câmbio com cotações do dia e atendimento direto pelo WhatsApp.

**Acesse:** https://cambioexpress.vercel.app

## Destaques
- Painel "Cotação de hoje" com valores de compra e venda (dólar, peso argentino, euro)
- Confirmação de valores e reserva pelo WhatsApp
- Seções de loja física, como funciona e dúvidas frequentes
- Responsivo e em um único arquivo

## Stack
HTML · CSS · JavaScript — publicado na Vercel.
